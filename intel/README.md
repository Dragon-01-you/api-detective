## 30 秒速查：一张表识别可疑中转站

| 你看到的 | 可能意味着 | 证据等级 |
|---|---|---|
| 模型名带 `gpt-5.6-sol` 这类行星后缀 | 自造 SKU，官方无此命名法 | 强旁证 |
| `/v1/models` 里 `owned_by` 混挂 4+ 家供应商（含 nvidia） | 「官方直连」话术与货源目录矛盾 | 强旁证 |
| 问不同品牌模型「你是谁」，答案逐字相同 + token 数相同 | 单后端换皮：一个模型贴多张皮 | **确证** |
| 身份问题的 prompt_tokens 远大于你输入的长度 | 有隐藏注入块（差值=注入体积） | 强旁证 |
| 推理模型拒答身份题，但思维链里讨论「我没有身份信息」 | 被剥掉真实身份卡 | **确证** |
| 中文身份题被改道、英文逃逸 | 网关内置中文验真流量探测器 | **确证** |
| usage 计数与 GPT 分词器（cl100k）吻合但卖的是 DeepSeek | 网关自算计费=转售链路实锤 | 强旁证 |
| ¥4 无限量日卡 | 低于官方成本，唯一盈利解=便宜后端贴牌 | 强旁证 |

## 与工具的关系

- 情报库是**纯数据**，独立可用；`api-detective` 的探针（[fingerprint.py](../api_detective/fingerprint.py)、[verdict.py](../api_detective/verdict.py) 等）是这些特征的**自动化执行器**
- 用工具跑出的新案件特征 → 欢迎脱敏后 PR 回填本库（附可复现判定方法）
- 每个特征的 `detection` 字段写明了人工复现方法——不装工具也能自查你正在用的中转站
